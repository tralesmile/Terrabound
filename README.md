# Terrabound

Free-to-play 2D sci-fi dig / automate / survive roguelite for web, Android and iOS. Dig deep, bank your loot before the battery dies, upgrade your suit, then build drones and survive the Hollow.

## Play and develop

```
npm ci
npm run dev      # dev server
npm run check    # typecheck + unit tests + build + browser e2e
```

Controls: A/D or arrows move, W/Space jump, mouse left dig, right build, B workshop at the pad, M mute. Touch: left side stick, right side dig.
